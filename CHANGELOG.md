# Changelog

All notable changes to this project are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-07-26

### Added

- Explicit-only `$recap` invocation for Codex App and Codex CLI.
- Fixed three-line output contract for current-conversation status.
- Literal fallbacks for conversations without enough evidence.
- `policy.allow_implicit_invocation: false`.
- Dependency-free contract validation on Windows and Ubuntu.
- English and Brazilian Portuguese documentation.
